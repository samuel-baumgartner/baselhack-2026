# Screenshot provenance

These are unaltered interface captures, selected for the repository README.

- `prism-home.png`: captured from https://prism.mvps.ch/ on 1 November 2026 using the shared browser preview, at 1280 × 800.
- `galaxus-catalog.png`, `galaxus-receipt.png`, `galaxus-updates.png`: existing local verification captures of the Galaxus browser preview. The original capture timestamp was not independently established for this README update.

The retail images show frozen demo products and synthetic commerce. They do not establish native assistant rendering, live inventory, payment processing or the current state of every deployment. The receipt identifier is a synthetic order reference, not a shopping-session capability.
